## 关于华为ICT大赛

华为ICT大赛是华为公司打造的面向全球高校的年度ICT赛事，2021年入围中国高等教育学会“全国普通高校大学生竞赛榜单”，是教育部认可的84项全国大学生学科竞赛之一。

大赛涵盖实践赛、创新赛、编程赛、挑战赛、算子赛、精英赛、教学赛等多个赛道。本仓库聚焦**实践赛-基础软件赛道**。

第十届大赛吸引了全球100多个国家和地区、超2000所高校、21万余名师生报名参赛。基础软件赛道**全国本科仅设8个一等奖名额**，与北京邮电大学、电子科技大学、厦门大学等顶尖高校同台竞争。



## 加分政策

持有对应技术方向的华为认证可在**省赛初赛**获得加分：

| 认证等级 | 加分   |
| :------- | :----- |
| HCIA     | +50分  |
| HCIP     | +100分 |
| HCIE     | +200分 |

同一技术方向取最高等级认证加分，不同技术方向证书可累计，**个人上限200分**，**团队上限600分**。加分证书需与报名账号一致。



## 致阅读者

知识从零基础开始一点点积累的。很少有那种一看就会的人，很多命令要敲好几遍才能记住，很多报错要查很久才能弄懂。但我想，能坚持走下去的人，本身就已经赢过了大多数中途放弃的人。

国赛的舞台离我们并不远。云南工商学院的团队用了三年时间，从省级二等奖一步步走到全国一等奖、全球三等奖。长沙民政职院的学生同样在全球总决赛拿到了基础软件赛道一等奖。他们的起点未必比我们高，但他们没有停下来。

备赛是一场长跑，不必急于求成。扎实走好每一步，把每个命令亲手敲一遍，每个报错亲手排一次，比收藏一堆“速成攻略”有用得多。

愿你在赛场上不留遗憾。我们总决赛见。
